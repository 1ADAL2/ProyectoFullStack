# Sistema de Inventario y Ventas

Proyecto Full Stack para la gestión básica de productos, inventario y ventas de una ferretería.

## Tecnologías

- **Frontend:** React
- **Backend:** Node.js
- **Base de datos:** PostgreSQL
- **Control de versiones:** Git y GitHub

## Funcionalidades

- Gestión de productos (CRUD).
- Control de existencias.
- Registro de ventas.
- Consulta de productos disponibles.
- Historial de ventas.

## Objetivo

Desarrollar una aplicación funcional para practicar la integración entre frontend, backend y base de datos mediante una API REST.
